# Provides-Value-or-LARP-
This project helps you measure actual value created with AI vs semi-productive, fancy UIs.

Many struggle to measure actual value created from maxxing out their MAX Claude and PRO Chatgpt subscription other than spending 200$ each. 
This tool provides a harness where an analyst tells you if value is provided using best practices used by McKinsey, BCG and Bain. 

You tell the analyst what your usecase is. It asks questions, spawns agents and tries to assess actual value creation.
